# vryl

Vryl is a TTRPG system for Foundry VTT that I have developed with my partner for our home game. The design is inspired heavily by World of Darkness's narrative gameplay, with elements of Pathfinder 2e and ICON's tactical combat.
I had initially implemented the system in Foundry's Custom System Builder, but we started to run into performance issues and limitations with that. When I decided to recreate the system from scratch, my goal for it was to leverage the nature of a *virtual* tabletop and make the experience of *playing* the system feel incredibly streamlined, almost as if you were playing a video game rather than engaging with forms and sheets.
